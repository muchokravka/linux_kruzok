Web server (nginx)

Inštalácia, konfigurácia a testovanie web servera nginx.

Teória 15 min Prax 30 min

29.1 Čo je web server?

Každá web stránka, ktorú navštíviš v prehliadači, niekde beží. Web server je program, ktorý prijíma požiadavky od klientov (prehliadačov) a posiela im späť obsah. Komunikácia prebieha cez protokol HTTP (port 80) alebo HTTPS (port 443).

Funguje to jednoducho: ty napíšeš v prehliadači adresu, tvoj počítač sa spojí so serverom a server odošle späť HTML stránku. Na našom VM si rozbeháme vlastný web server, aby sme videli, ako to celé funguje odvnútra.

Klient-server model
Klient (prehliadač) sa pýta, server odpovedá. Ty si na krúžku budeš serverom aj klientom zároveň, pretože všetko beží na jednom stroji.

29.2 Inštalácia nginx

nginx (vyslovuj "engine-x") je jeden z najpopulárnejších web serverov na svete. Je rýchly, spoľahlivý a ľahko sa konfiguruje. Nainštalujeme ho cez správcu balíkov.

Inštalácia nginx (Debian/Mint)
student@debian:~$ sudo apt update ... student@debian:~$ sudo apt install nginx -y Čítanie zoznamov balíkov... Hotovo ... student@debian:~$
Inštalácia nginx (Fedora)
student@fedora:~$ sudo dnf install nginx -y ... student@fedora:~$

29.3 Spustenie a kontrola

Po inštalácii treba nginx spustiť a nastaviť, aby sa spúšťal automaticky pri štarte systému. Použijeme na to systemctl, ktorý už poznáme z hodiny 21.

Spustenie nginx
student@debian:~$ sudo systemctl enable --now nginx student@debian:~$ systemctl status nginx ● nginx.service - A high performance web server and a reverse proxy server Loaded: loaded (/lib/systemd/system/nginx.service; enabled) Active: active (running) since ... student@debian:~$
Test pomocou curl
student@debian:~$ curl localhost <!DOCTYPE html> <html> <head><title>Welcome to nginx!</title>... </html> student@debian:~$ curl 127.0.0.1 <!DOCTYPE html> <html> <head><title>Welcome to nginx!</title>... </html> student@debian:~$
Čo je curl?
curl je príkaz na odosielanie HTTP požiadaviek priamo z terminálu. Je to prvý nástroj, ktorým testuješ, či web server funguje. localhost a 127.0.0.1 odkazujú na ten istý stroj, na ktorom sedíš.

29.4 Vlastná stránka

Úvodná stránka nginx je pekná, ale naša bude lepšia. Predvolený obsah sa nachádza v /var/www/html/. Upravíme si ju.

Vytvorenie vlastnej stránky
student@debian:~$ sudo cp /var/www/html/index.nginx-debian.html /var/www/html/index.nginx-debian.html.bak student@debian:~$ sudo nano /var/www/html/index.html # Vlož tento obsah: <!DOCTYPE html> <html lang="sk"> <head><title>Moja stránka</title></head> <body> <h1>Ahoj, toto je môj web server!</h1> <p>Beží na nginx v mojom Linux VM.</p> </body> </html> student@debian:~$ curl localhost <!DOCTYPE html> <html lang="sk"> <head><title>Moja stránka</title></head> <body> <h1>Ahoj, toto je môj web server!</h1> <p>Beží na nginx v mojom Linux VM.</p> </body> </html> student@debian:~$
Zapamätaj si
Obsah stránok nginx sa nachádza v /var/www/html/. Súbory tam píšeš ako root (pomocou sudo), pretože ten adresár vlastní systém. Ak chceš stránku vytvoriť normálnym používateľom, musíš opraviť oprávnenia.
